# JavaScript 1 Course Assignment - Rainy Days API

This project is my submission from the course assignment for JavaScript 1 in the Noroff school of digital media and technology FED 1 programme.
My first ever coding project featuring JavaScript.
This project is not applicable for professional use and should be viewed as a sandbox for my learning development in my first year studies.

The course assignment brief gave us the opportunity to use previous project files to implement e-commerce API for a fictional e-commerce brand, Rainy Days.
Our task was to integrate asynchronous fetch and display of products from a given API. Create a cart system and checkout flow.

This website lacks full functionality with payment and checkout. Each page should be viewed as a mock of what a real world application could look like.

## Features

- Index page with product list
- Single product details page for each product
- Cart/checkout page
- Confirmation page
- Hamburger dropdown menu with use of max-width/auto overflow CSS trick
- Full responsive scaling across viewports from 320px VW to 1920px VW, with use of @media breakpoints
- Implementation of icons and fonts via FontAwesome free library scripting
- Asynchronous fetch requests for all products and single products
- Filtering buttons for gender of products from API
- Cart system with use of localStorage
- Price and quantity calculations
- Rounding of decimals with parseFloat and toFixed
- Error classes
- Custom toast notifications
